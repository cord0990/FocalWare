# Conexiones
Este archivo fue solicitado para facilitar el trabajo en equipo del mockup hecho en figma.
Resume todas las conexiones interactivas de los botones dek mockup.

El formato de las conexiones es el siguiente:

```markdown
### [Pantalla]
[botón] -> [pantalla a la que enlaza]
```

## Vista Desktop
Conexiones en la vista de escritorio.

### Inicio de Sesión
1. Sign in -> Pantalla de Inicio (Post Log In)
2. Sign up -> Crear Cuenta
3. Forgot Password? -> Recuperar Contraseña

### Recuperar Contraseña
1. Send Code -> Recuperar Contraseña - Código

### Recuperar Contraseña - Código
1. Validar Código -> Recuperar Contraseña - Contraseña

### Recuperar Contraseña - Contraseña
1. Crear Nueva Contraseña -> Inicio de Sesión

### Crear Cuenta
1. Register -> Pantalla de Inicio (Post Log In)

### Pantalla de Inicio (Post Log In)
1. Foto de Perfil -> Pantalla de Inicio (Post Log In) - Configuración

### Pantalla de Inicio (Sin Log In)
1. Iniciar Sesión -> Inicio de Sesión
2. Crear Cuenta -> Crear Cuenta
